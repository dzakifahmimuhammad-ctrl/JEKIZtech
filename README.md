# JEKIZtech
# 👋 Halo, Saya Jekiz!

Saya adalah seorang siswa SMK jurusan **Teknik Audio Video** yang berfokus pada pengembangan perangkat keras (*hardware engineering*), desain PCB sirkuit audio/mikrokontroler, dan sistem tertanam (*embedded system*).

---

### 🛠️ Audio & Hardware Engineering Focus:

- 🔭 **Sedang mengerjakan:** Desain sasis robot berbasis STM32F401 sekalian riset integrasi sistem kontrolnya.
- 🤝 **Tertarik kolaborasi dalam:** Proyek *audio electronics*, *open-source hardware*, atau modifikasi dan pembuatan sistem penguat suara (*amplifier tuning*).
- 🎯 **Sedang mempelajari:** Arsitektur mikrokomputer STM32, teknik desain PCB rendah *noise* di KiCad, dan optimalisasi sistem akustik.
- 💬 **Tanya saya tentang:** Skematik rangkaian audio/elektronika di KiCad, perakitan komponen, dan dasar-dasar pemrograman C/C++.
- ⚡ **Fun Fact:** Buat anak Audio Video, *troubleshooting* nyari sumber suara "dengung" (*noise*) di dalam rangkaian elektronik itu kayak lagi main game detektif—susah tapi bikin nagih pas ketemu solusinya!
